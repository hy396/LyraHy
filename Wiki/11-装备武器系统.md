## 待撰写的内容提纲

### 一、装备系统三件套

- `ULyraEquipmentDefinition`（数据）：Actor 生成配置 + AbilitySet
- `ULyraEquipmentInstance`（运行时对象）：Owner + SpawnedActors
- `ULyraEquipmentManagerComponent`（装备管理器，挂在 Pawn）

### 二、EquipmentInstance 的生命周期

- `EquipItem` / `UnequipItem` 时发生什么
- AbilitySet 的授予/回收
- 网络复制（装备列表同步）

### 三、Inventory 和 Equipment 的区别

- Inventory：拥有（可堆叠、可丢弃）
- Equipment：当前装备（武器、装甲、配件）
- 两者怎么协作

### 四、武器继承链

```
ULyraEquipmentInstance
  ↓
ULyraWeaponInstance          (通用武器)
  ↓
ULyraRangedWeaponInstance    (远程武器，含命中检测参数)
```

### 五、一次开火的完整调用链 ★

```
按键 IA_Shoot
 → LyraInputComponent (bound to Ability.Weapon.Fire Tag)
 → ASC.TryActivateAbilityByTag
 → ULyraGameplayAbility_RangedWeapon.ActivateAbility
   → PlayMontage (Task)
   → OnTargetDataReadyCallback
     → PerformLocalTargeting / PerformServerTargeting
     → WeaponTrace 射线/散射检测
   → 创建 GameplayEffectSpec (Damage)
   → ApplyGameplayEffectSpecToTarget
 → Target.HealthSet.Health 减少
 → 触发 OnDamaged → GameplayCue 播放血花
 → 死亡？触发 Ability_Death
```

### 六、散射、弹药、冷却实现

- 散射：`SpreadAngle` 属性 + 随机射线
- 弹药：武器组件上的 `Ammo` Attribute + Cost Effect
- 冷却：Ability 的 `CooldownGameplayEffect`
